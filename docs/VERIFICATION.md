## 4. 已知限制 / 未验证项

- QQ 官方机器人能力受开放平台权限与审核限制；gif/webp 直传取决于账号权限，失败会自动降级为文字并记录日志。
- 多模态识别依赖外部 OpenAI 兼容接口，具体效果与费用由所配置的模型决定；接口失败会自动降级为 `[图片]` / `[语音]` / `[视频]` 占位，不影响聊天。
- 控制台内嵌页面使用 iframe 呈现，未做逐像素的浏览器视觉回归；已在应用内实际使用验证。
- 未进行高并发消息压力测试（同一会话内串行处理，跨会话并发）。
- 修改 `admin.path` 后需重载插件（HTTP 路由在启动时注册）。
