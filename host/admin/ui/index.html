对话

机器人的人格、模型、记忆与命令权限都在这里；每个子标签只负责一类设置，保存时只提交当前页。

管理员 openid 支持 user_openid / member_openid / union_openid；在 QQ 里发 #我的id 可查看当前账号标识。

多模态

输入识别与输出生成放在同一个功能模块里：识别负责“看懂入站媒体”，输出负责“生成图片 / 语音 / 视频”，两者不再分散在配置页和独立路由。

多模态识别（输入）：图片 / 语音 / 视频先转成文字描述，再注入对话上下文。没有配置时只使用媒体占位标记，不影响聊天。
多模态输出（图片 / 语音 / 视频）

接口配置、角色参考图、生成试跑与作品库都在这个子标签内。

    接口配置

    每类接口可独立使用不同服务商；API Key 只写不读。

    生成试跑

    会实际调用第三方接口并产生费用；提示词命中角色名 / 触发词时会自动带入角色参考图。

    聊天内用法

    • #画 一只橘猫 生成并发送图片
    • #语音 晚安，好梦 生成并发送语音
    • #视频 海边日落 生成并发送视频

    默认仅管理员可用；权限在「对话 → 命令与权限」，总开关在下方「输出总开关」里调整。

    最近生成

    作品保存在插件 data/outputs/，可按保留策略自动清理。

    表情包

    图库导入、打标、图层与表情包行为设置都在同一页，不再把“导入”和“配置”拆到两个路由。

    已选 0 项
    表情包行为设置：启用开关、图层策略、自动抓取、回复概率与提示词标签数量。图库导入与打标在「图库与打标」子标签。

    预算

    用量查看和限额设置放在同一页；用量页负责仪表盘与明细，设置页负责限额、单价与拦截文案。

    限额使用情况

    按会话用量

    最近调用

    限额为 0 表示不限制；修改后从下一次模型调用开始生效。

    会话

    查看历史消息、摘要与长期事实，可压缩上下文、抽取记忆或覆盖人设。

    从左侧选择一个会话查看详情

    人员

    记录聊天中出现过的用户画像与长期事实，也可用于查找管理员 openid。

    系统设置

    QQ 接入、管理后台与日志级别集中在这里；聊天命令权限已经移到「对话 → 命令与权限」。

    管理后台入口路径修改后需要重新加载插件才会生效；管理员 openid 在「对话 → 命令与权限」。

    运行日志

    插件最近写入的日志（最多 300 条），按时间从旧到新排列；日志级别与保留行数在「系统设置 → 日志与调试」。
