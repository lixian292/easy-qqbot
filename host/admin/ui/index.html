多模态输出

通过第三方 API 生成图片 / 语音 / 视频：先在这里配置接口，再试跑并管理作品。生成内容可在 QQ 聊天中用 #画 / #语音 / #视频 调用。

    接口配置

    每类接口可独立使用不同服务商；API Key 只写不读。

    生成试跑

    会实际调用第三方接口并产生费用，请确认配置后再试；提示词命中角色名 / 触发词时会自动带入角色参考图。

    聊天内用法

    • #画 一只橘猫 生成并发送图片
    • #语音 晚安，好梦 生成并发送语音
    • #视频 海边日落 生成并发送视频

    默认仅管理员可用；权限、是否发送到 QQ、模型主动调用开关都在下方「输出总开关」里调整。

    最近生成

    作品保存在插件 data/outputs/，可按保留策略自动清理。

    配置

    按分区查找和修改配置；保存后写入 data/config.json，QQ 连接会按新配置自动重启。

    配置分区
      多模态输出的接口配置已独立到「多模态输出」页面（图片 / 语音 / 视频各自的 API、模型与试跑）。

      提示：AppSecret 与多模态 API Key 只显示掩码，输入框留空表示不修改；留空或非法的数值会被插件回退为默认值。

      表情包
